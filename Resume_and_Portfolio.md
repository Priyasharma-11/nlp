# Portfolio description
ResearchMind is a local-first scientific literature intelligence application built with Python, Streamlit, SQLite and NLP/ML tooling. It integrates academic metadata ingestion, PDF extraction, lexical and optional semantic retrieval, evidence-linked summaries and comparisons, citation graphs, extractive question answering, experimental claim assessment and corpus analytics. The release candidate includes automated tests, offline benchmark runners and Docker/CI configuration. Scientific model quality and deployment remain to be validated.

## Resume-ready bullets (adapt only to work you can explain and demonstrate)
- Developed a modular Python research intelligence prototype integrating scientific metadata APIs, local PDF ingestion and SQLite persistence with page-level provenance.
- Implemented TF-IDF and BM25 retrieval, weighted rank fusion, classical NLP and optional transformer adapters for scientific document discovery.
- Built extractive paper analysis, multi-paper comparison, evidence-backed citation graphs and a local-first research assistant with citation validation and fallback behavior.
- Added offline SciFact/BEIR-format evaluation, 58 passing controlled automated tests in a Linux sandbox, and Docker/CI configuration for local deployment preparation.

## Short recruiter pitch
A research workspace that makes scientific evidence inspectable rather than merely generating answers. The core baseline works through lexical retrieval and extractive evidence; optional AI models extend it after local validation.
