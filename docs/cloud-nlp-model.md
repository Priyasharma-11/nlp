# English NLP on Community Cloud
The cloud requirements install spaCy 3.8 and its small English model (en_core_web_sm 3.8.0) together. Sentence boundaries, POS tagging, lemmatization and named entity recognition use that model. NLTK remains available for stemming and optional fallback processing; no Punkt or WordNet downloads are required in the normal spaCy path. The model is general English, not a scientific-specialized NER model. If the build cannot install it, inspect deployment logs. The existing fallback continues to report genuinely missing resources. Rebuild the app after changing requirements. No user text is sent to the model provider.
