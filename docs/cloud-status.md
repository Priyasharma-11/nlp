# Cloud Edition verification and limits

Cloud-only entrypoint, consent, session-local SQLite in memory, reset clears session-state values and disposes engine, no persistent database path, no shared literature-query cache, no arbitrary local model path inputs, no transformer/Word2Vec inference or full SciFact UI in cloud mode. Local source and portfolio retained. Cloud caps: 30 papers, 10 collections, 4 PDFs, 5 MiB per PDF, 15 MiB aggregate original PDF bytes, 60 source records, 5,000 passages, 500 activity rows; SQLite page-count target 12,288 (approximately 48 MiB at 4 KiB/page). These are per-session limits, not a hard process-wide RAM quota. Backend parser still has 300-page and 2-million-character limits. Public metadata search returns 5 results per page; API throttling is not coordinated globally. No external AI service or paid API was connected.

Storage is temporary, not guaranteed erased immediately at disconnect, not secure memory erasure, not an authentication system. Streamlit may retain session/upload references until cleanup. No user-selectable persistent storage; distinct session objects have separate DB engines. Host operators can potentially access server data. Do not enter confidential material. No production authentication, process-level parsing sandbox, encryption guarantee, abuse prevention, independent security audit or durable user data. Multiple simultaneous sessions can exceed free hosting resources. Optional spaCy and NLTK linguistic resources are not bundled; fallback behavior is explicit. Some untrusted display paths still require security review. Use private app sharing; never publicly expose the local entrypoint.

Test execution: see cloud-test-output.txt. Tests use synthetic inputs; no scientific performance claims. Streamlit could not be installed from the available package index, so both UI test modules were skipped. Browser isolation, consent controls and cloud build require actual runtime verification. Python compile check performed. No Docker build, live APIs, real model weights or scientific datasets were verified. Previous Phase 8 blockers remain except the specific cloud changes described here. No deployment, account creation or remote repository was performed.
