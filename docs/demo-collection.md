# Presentation demo

After accepting the privacy notice, click **Load demo papers** in the sidebar. Six real papers are saved to the current temporary workspace. Repeat loading is safe and does not create duplicate records. The Welcome page shows links and editorial summaries. Overview shows actual saved counts. Library shows the collection. Semantic search supports BM25 queries such as "scientific document embeddings". Knowledge graph shows author and topic relationships from curated metadata. Paper analyzer displays source records; original abstracts and PDF evidence must be added separately to demonstrate evidence-based answers. Editorial notes are not author abstracts and are deliberately excluded from evidence retrieval. No fabricated citation counts, claims, benchmark scores or full texts are supplied.
